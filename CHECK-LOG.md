## Operator data

Stats were read from the operator boards. Roles and best range come from the Operators Profiles Reference sheet.

| Operator | Check |
|---|---|
| Doc | Reference sheet highlights short and medium range. Site shows short. |
| Pulse | Reference sheet highlights short and medium range. Site shows short. |
| Tachanka | Reference sheet highlights medium and long range. Site shows medium. |
| Recruits (all four) | Boards show two plain dice and two boxed dice per range, some with an arrow mark. The site lists all four dice. Check how the boxed dice work. |
| Thermite | Destroy rating on the board is orange. His gadget uses a red rating. Confirm. |
| Caveira | Board has two named abilities. The site uses Questioning Knife as the gadget name. |
